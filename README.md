# Dulce Capricho — versión original

Esta carpeta conserva el `index.html` original y las imágenes proporcionadas, organizadas para que coincidan con las rutas `images/...` del HTML.

## Publicar en GitHub y Vercel
1. Sube `index.html`, `README.md` y la carpeta `images` a la raíz del repositorio de GitHub.
2. En Vercel, importa ese repositorio.
3. Selecciona el despliegue como sitio estático. No requiere comando de compilación.
4. Publica el proyecto.

## Importante sobre el video
El HTML original busca el video en `videos/anuncio_dulce_capricho.mp4`, pero ese archivo no estaba entre los archivos recibidos. Para conservar la versión original, no cambié el HTML ni sustituí el reproductor. Si quieres que el video funcione al publicar, añade ese archivo a `videos/anuncio_dulce_capricho.mp4`.
